# RR-01 — HSM wire reroute support

**Workstream:** RR (../RR-PLAN.md). **Layer:** Hrot.Hsm.Editor command sink. **Depends:** none. **Size: trivial.**

## Goal

Handle the three reroute commands in `HsmCommandSink` so users can insert / drag / delete reroute waypoints on HSM transition wires. The NodeEditor UI already emits these commands and renders the dots + bent beziers; the model + `.hsm.json` persistence for `TransitionNode.Waypoints` already exist. Only the sink handling is missing.

## Implementation

`Hrot/Subsystems/AI/Hrot.Hsm.Editor/Host/HsmCommandSink.cs` — add three cases to the `Apply` switch (before the `default` arm at ~line 78):

```csharp
case GraphCommand.InsertReroute ir:   ApplyInsertReroute(ir); break;
case GraphCommand.MoveReroute mr:      ApplyMoveReroute(mr); break;
case GraphCommand.RemoveReroute rr:    ApplyRemoveReroute(rr); break;
```

Handlers (resolve the transition via its VisualId == LinkId):

```csharp
private void ApplyInsertReroute(GraphCommand.InsertReroute cmd)
{
    var t = _asset.FindTransitionByVisualId(cmd.Link.Value);
    if (t is null) return;
    t.Waypoints.Add(cmd.Position);   // append (v1; nearest-segment ordering deferred)
}

private void ApplyMoveReroute(GraphCommand.MoveReroute cmd)
{
    var t = _asset.FindTransitionByVisualId(cmd.Link.Value);
    if (t is null) return;
    if (cmd.WaypointIndex < 0 || cmd.WaypointIndex >= t.Waypoints.Count) return;
    t.Waypoints[cmd.WaypointIndex] = cmd.NewPosition;
}

private void ApplyRemoveReroute(GraphCommand.RemoveReroute cmd)
{
    var t = _asset.FindTransitionByVisualId(cmd.Link.Value);
    if (t is null) return;
    if (cmd.WaypointIndex < 0 || cmd.WaypointIndex >= t.Waypoints.Count) return;
    t.Waypoints.RemoveAt(cmd.WaypointIndex);
}
```
