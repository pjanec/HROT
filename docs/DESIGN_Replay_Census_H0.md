# H0 — the replay census: does a recording hold what replay needs, and only that?

🔒 User, `2026-10-25`: *"it relies on that snapshots really save what should be saved … are we saving what needs to be saved to recording?
aren't we saving what should not be?"* ⇒ every `[ComponentId]` type asked ONE question: **when a recording is REPLAYED, must this type's
value come from the recording?** Premise (replay-and-modules §2.1): in replay the Input / Simulation / PostSimulation / NetworkLifecycle
groups are off, so a view-read type that is not recorded is MISSING in replay — nothing recomputes it.

- Coverage not proven (check_index_coverage unavailable through the CLI). ### 🔴 `SquadDrillTrace` is NoReplay but the Brain tab and the squad debug route read it
